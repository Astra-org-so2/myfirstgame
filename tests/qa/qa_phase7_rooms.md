## A. ПК-редактор (Godot 4.7.2, F5)

- [ ] Запуск без ошибок в Output (скрипт-ошибки = 0; лагер:
      CampWorld как в Phase 6, НО без пьедесталов cannon/staff —
      они теперь в зонах).
- [ ] **Переход в зону:** подойди к любому из 7 открытых
      зона-гейтов (каменных маркеров по кругу) → шаг в проём →
      уровень меняется: комната(и) зоны (пол/стены/проёмы/
      монолиты в проёмах), туман гуще чем в лагере, свет зоны.
      Лагер-слой (NPC/костёр) не виден в зоне.
- [ ] **Назад в лагерь:** выйди из входной комнаты зоны через
      проём к лагерю (camp_exit, «к лагерю» сторона) → лагерь
      как был (NPC на местах, костёр, туман прежний).
- [ ] **Шахта → рудник:** в Mine пройдите цепочку до конца —
      последний проём ведёт в Undercroft (аренa, workbench,
      emissive-луч, entry-проёмы с двух сторон). В Undercroft
      выхода в лагерь НЕТ (sealed — ADR-016); назад — только
      через входной проём в последнюю комнату шахты.
- [ ] **Cannon в шахте:** на входе в шахту — пьедестал (cannon):
      (E) → в loadout (+1), метка «It's heavy. Use it once. — E.»,
      пьедестал «уже ваш»; выйдешь и вернёшься — пьедестала нет
      (перманентно, WorldState).
- [ ] **Staff в святилище:** на входе в Old Shrine — пьедестал
      (staff): (E) → loadout (+1), «It sees what you left. Use
      it gently. — E.».
- [ ] **Враги в зонах:** спавны по таблице зоны (условия
      slayer/runner/explorer по профилю): в шахте 2–3 (base/
      fast/big), на смотровой — Watcher (+fast при runner), в
      деревне — base (+wanderer при explorer). Враги не выходят
      за пределы уровня (nav-кольцо уровня).
- [ ] **Детерминизм:** два запуска подряд (один seed сессии
      20260917) → одинаковая раскладка (комнаты, варианты,
      спавны). F1–F8 debugger: F3 (seed display) — раскладка
      совпадает с прошлым запуском.
- [ ] Data-driven: новая комната = .tres в data/rooms/ (+ id в
      pool зоны data/areas/*.tres) — без кода. 100-сидовый
      прогон: `HARNESS_TIMEOUT=180 ./tools/run_tests.sh unit`
      (сьют rooms) — 100/100 без fallback (в логе нет
      «using the reference layout»).

## B. Мобильный контекст (Android-first, ADR-021)

- [ ] Переходы на тач-джойтике: проходы 1.7 м проёмов
      проходны на всех aspect (портрет не поддерживается —
      landscape, как и лагерь).
- [ ] Бюджет зоны: 1–3 комнаты × (1 PointLight без теней +
      примитивы) — draw calls уровня ≈ 30–60 (меньше лагера с
      деревьями); свет — один omni без shadow на комнату.
- [ ] Память: смена уровня освобождает визуалы уровня
      (queue-free → immediate free, утечек не накапливается при
      N переходах — по памяти процесса за 10 переходов).
