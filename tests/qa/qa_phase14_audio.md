# QA Phase 14 — Audio (ручной pass владельца)

Дата: 2026-09-22. Состояние: headless-тесты зелёные (unit 945 /
integration 501). Рендер headless-риг НЕ валидирует: громкость
восприятия, LUFS, артикуляцию мелодии — только структура (buses,
streams, уровни в dB, логика переключений). Слушать — на устройстве.

## A. Музыка — «The Wound» ×5 (GDD §7)

Одна мелодия, 5 обликов. Игрок должен узнавать мелодию в каждом
слое (это тест дизайна, не качества).

- [ ] **Normal** (лагерь/деревня/шахта/все зоны по умолчанию):
      тихая, close, «мuted» (WORLD_BIBLE §1). Не давит на SFX.
- [ ] **Memory** (пост-босс, любой мир, кроме Undercroft): светлее,
      выше октавой, длинный хвост (реверб-тэйл). «Мир помнит».
- [ ] **Echo** (Passive Echo рядом, RUN 02+): перевёрнутые фрагменты
      (каждый 4-й нот «играет назад») + tapped-эхо. «Другой вы».
- [ ] **Archivist** (арена THE FIRST): monochrome-синус, стаккато,
      низкий дрон D2, rust-metal акцент на сильных долях.
- [ ] **Ending** (Undercroft после босса: дверь открыта, туман
      тоньше): полная — две гармоники, тёплый пад, финальная фраза
      вверх на октаву. «Рана, открытая».
- [ ] **Crossfade 1.5 c** при каждом переключении — без скачка
      громкости (слушать переход Normal->Echo и Echo->Ending).
- [ ] **Stinger** (reveal босса, вход в Undercroft до победы):
      3 c нарастание D2->D3 + удар + звон. Играет один раз.

## B. Ambient-слои (6, по зонам)

- [ ] **Camp** (лагерь): ветер + треск костра + низкий «бревно».
- [ ] **Wild** (деревня/башня/мост): ветер + редкие птицы + скрип.
- [ ] **Stone** (храм/врата): низкий ветер + гул камня + тики.
- [ ] **Mine**: рокот + капли (каждая с одним эхом).
- [ ] **Lake** (озеро): плеск (0.4 Hz-набухание) + ветер + одна птица.
- [ ] **Undercroft**: дрон D2/D3, «дышит» раз в 16 с + два глубоких
      удара (5 c, 11 c).
- [ ] Смена зоны = кросс-свап без щелчка; loop 16 s не слышен.

## C. SFX (12 кью)

- [ ] swing/hit/riposte/hurt/shot/pickup (P4/P6) — нет регрессии.
- [ ] door (смена зоны), seal (смерть босса), death (падение —
      тело, не голос), note (бумажный свист+пинг), ui (тик),
      echo (шёпот-набухание при появлении Echo).
- [ ] Пул (3 слота): быстрая серия (3+ замахов) не теряется
      (oldest-steal), нет «залипания».

## D. Settings (P14-экзит)

- [ ] F9 (debug build) — панель: Master/Music/SFX/Ambient + Mute.
- [ ] Слайдеры применяются ЖИВО на бусах (в dB: 0.5 = -6 dB,
      0.25 = -12 dB); Mute = пол (-80 dB) по всем бусам.
- [ ] Значения — dict AudioManager.get_settings() (P15 сохранит
      в save; persistence — фаза P15, честно).
- [ ] Мобильная вёрстка: центральный бокс (16:9–20:9 safe),
      thumb-sized строки (>= 44 px), tap/drag по трекам.

## E. Mobile (device QA, P16)

- [ ] Громкость на референсе (Snapdragon 7-class): музыка слышна
      под SFX, ambient не маскирует footstep-тихие кью.
- [ ] LUFS: цель -20..-16 LUFS интегрально (измерить на устройстве;
      headless не валидирует).
- [ ] No clipping: пик файлов = 0.85 (музыка/stinger) / 0.35
      (ambient) / 0.9 (SFX) — проверено unit-тестами; на устройстве
      — без клиппинга в mix-е (3 кью + музыка одновременно).
- [ ] Батарея/терм.: аудио-обработка легкая (12 WAV-стримов,
      ~4.8 MB в памяти 11025 Hz mono 16-bit).
- [ ] 11025 Hz — нет audible-aliasing (контент < 5.5 kHz).

## F. Что headless НЕ проверяет (честно, ADR-033)

- Восприятие: качество тембров, узнаваемость мелодии, LUFS.
- Громкость mix-а в реальных условиях (buses-уровни — да, ухо — нет).
- Переносимость 11025 Hz на конкретный DAC устройства.

## G. Регенерация и инварианты

- `python3 tools/utils/gen_audio.py` — byte-идентичная
  регенерация (seeds зашиты); md5-стабильность проверена.
- Музыка: 5 × ~24 s (memory/echo +1.3/1.5 s — реверб-тэйл),
  ambient 6 × 16 s, stinger 4 s. Итого ~4.8 MB.
- SfxLibrary: 12 кью, все детерминированы (seeds), все пик < 0.9.
