## A. ПК-редактор (Godot 4.7.2, F5)

- [ ] Запуск без ошибок в Output (скрипт-ошибки = 0; в лагере:
      4 NPC (Mara в костюме + 3 капсулы), пьедестал с cannon
      (у стола) и пьедестал со staff (у записки), костёр —
      интерактивный).
- [ ] **Pickup (scripted):** подойди к cannon, (E) → оружие
      «взято»: пьедестал пуст (метка «It's already yours.»),
      Q (weapon_switch) → в руке cannon (визуальный смена
      контроллера), ещё (E) — ничего не происходит (повторно
      взять нельзя, навсегда).
- [ ] **Cannon:** медленный windup (~1.8 s) → выстрел (снаряд,
      15 m, лёгкий разброс). Боезапас 5, перезарядка 1 (1.5 s);
      после — пуст до респавна. SPECIAL «Break»: 2 выстрела по
      цели (CD 40 с — slow_burn 40/30/25).
- [ ] **Staff (у записки):** 4 действия — ATK (Shatter, 40 dmg),
      SPC (Read — маркеры на целях), V (Soothe — ближайший враг
      «засыпает» ~5–7 с, GENTLE HAND), B (Disrupt — CD
      тратится, эффекта нет до Phase 9 — честно, без фейк-свечения).
      Каст 1.5 s, прерывается получением урона.
- [ ] **NPC trust (Mara):** 2 разговора (E, E) — реплики
      уровня 0; третий (E) — скриптовый help («The wood.
      There. ...Thank you.») → trust 1 (реплики уровня 1).
      Смерть на экране: EMBER (её gift) появляется среди
      карточек (pool = 12 + NPC-gated).
- [ ] **NPC-gate (цена постоянна):** убей NPC (бьётся, 50 hp) →
      его Inheritance НАВСЕГДА исчезает из пула (следующая
      смерть: его gift среди карточек нет; trust сброшен;
      реплика-последствие на метке).
- [ ] **Экран смерти:** 3 карточки (имя + строка, без цифр),
      таймбар 8 с; выбор карточки (клик) — перманентен; 8 с
      без выбора — мир выбирает (детерминированно по сиду);
      смерть → респавн ≤ 10 с.
- [ ] **Костёр:** без EMBER — (E) → «The fire is cold.» (hp
      не меняется); выбери EMBER (смертный экран или debugger)
      → костёр лечит полностью.
- [ ] **Предметы (костёр ×3/run):** убитый враг с 1/10 шансом
      оставляет колоду; (E) → в bag (I) — 4×3 сетка; tap слота
      → +30 hp; 3-й — больше не дропается.
- [ ] **Second Chance:** выбери (смертный экран) → смертельный
      удар = HP 1 + free-dodge с расширенным i-frame 0.5 s
      (1 раз за run).
- [ ] **Echo Step:** выбери → уворот оставляет afterimage
      (0.5 s); враг, смотревший на след, замирает (0.5/0.75/1.0 s
      по уровню).
- [ ] Data-driven: новый Inheritance = один .tres в
      data/inheritances/ + имя в ProgressionState.INHERITANCE_FILES
      (без переписывания ядра).

## B. Устройство (Android, touch)

- [ ] Тач-слой живой (регрессия Phase 6!): джойстик двигает
      игрока, кнопки ATK/DODGE/SPC/E/INV/SWP/CALM/BRK реагируют
      на tap (подсветка) и удерживание. До Phase 6 wiring был
      на несуществующем `_input_event` — на устройстве кнопки
      молчали (найдено при ревизии, зафиксировано
      touch_scene-тестом).
- [ ] Экран смерти на тач: тап по карточке выбирает (не только
      мышь); таймбар виден; выбор ≤ 10 с.
- [ ] Bag на тач: INV-кнопка открывает/закрывает; тап по слоту
      использует предмет.
- [ ] Aspect-ratio: карточки экрана смерти и bag-сетка не
      выходят за экран на 9:16 и 20:9 (раскладка в пикселях от
      viewport).
- [ ] Performance (тепловой): с 4 NPC + 5 врагами + прогресс-
      ноды — 60 fps без просадок на референс-железе (Adreno);
      прогрессия — CPU-тривиальна (словари/таймеры), рисок —
      только визуал (Label3D ×4, маркеры).
