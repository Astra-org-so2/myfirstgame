# QA Phase 3 — First environment (camp hub)

Цель: лагерь-хаб играбелен, читаем с одного взгляда (огонь — центр),
палитра/туман соответствуют WORLD_BIBLE §1/§1.1, правило no-filler
выполнено (каждый объект несёт бит), мобайл-перформанс в бюджете
(ADR-021). Риг-покрытие: 150 проверок — 43 smoke (+ CampWorld),
player_data 16, movement_logic 29, camera_rig 14, touch_layout 4,
camp_layout 15 (валидация данных: 8–12 деревьев, 3 палатки, 8 зон,
наративные якоря, negative-пути), player_scene 15, camp_scene 14
(сборка из данных + interactable-прототип: prompt/edge-сигнал/скрытие
при уходе, через mock-порт на ручном clock, ADR-022). В редакторе/на
устройстве проверяется то, что риг не видит: рендер, туман, свет,
feel, перформанс.

## A. ПК-редактор (Godot 4.7.2, F5)

- [ ] Запуск без ошибок в Output (вкл. отсутствие ошибок скриптов и
      «Failed to load resource»).
- [ ] Спавн у края хаба (вход по тропе), столб с надписью (A2) —
      виден ДО лагеря, читается как «старое место».
- [ ] Огонь — ЕДИНСТВЕННЫЙ тёплый источник света: вокруг него тёплый
      свет, дальше — холодный green-grey. Остальная палитра —
      приглушённая (WORLD_BIBLE §1).
- [ ] Туман: дымка на горизонте, лагерь читается целиком, дальний
      план мягко гаснет (fog ~80%).
- [ ] 3 палатки вокруг огня, обращены к нему; цвета различимы
      (палатка Мары / пустая / «не-человеческая» — по тону).
- [ ] Предметы у лагеря: столб (тропа), доска с запиской, стол с
      двумя кружками, чайник у огня.
- [ ] Подход к интерактивному предмету (любой из 4-х): появляется
      промпт (Label3D) «…(E)»; наведение мягко пульсирует.
- [ ] Нажатие E у предмета: сигнал interacted срабатывает ОДИН раз
      (удержание кнопки — не повторяет); эффект пока заглушка
      (Phase 4/10/11) — в Output/лог видно срабатывание.
- [ ] Уйти от предмета — промпт исчезает.
- [ ] 8 каменных монументов по кругу (silhouette зоны, геометрия
      Phase 7), обращены к лагерю.
- [ ] На горизонте в тумане силуэты: сторожевая вышка + ворота.
- [ ] Стены хаба: невидимые (только коллизия), сквозь не пройти.
- [ ] Движение/камера/dodge из Phase 2 не сломаны (регрессия).

## B. Android-устройство (debug-экспорт или Godot-remote)

- [ ] Та же сцена: лагерь виден и читаем, туман/свет без артефактов
      (проверка Adreno; Mali — Phase 16/17).
- [ ] Проход по тропе к лагерю: спавн → столб → огонь (A2-бит
      работает в движении).
- [ ] Тач: USE-кнопка вместо E — промпты и интеракты работают;
      джойстик + USE одновременно.
- [ ] 60 fps при обходе лагеря (F1 overlay / `adb shell dumpsys
      gfxinfo`), просадок на смене видимости огня нет.
- [ ] 5 минут игры: температура устройства не ощутимо растёт
      (огонь — один OmniLight3D, без динамических теней).
- [ ] Aspect 20:9: промпты (Label3D) читаемы, не обрезаются.
- [ ] Одиночный OmniLight + DirectionalLight: проверка на слабых
      GPU (SD7) — без «горящих» пикселей/завываний альбедо.

## C. Дизайн-чек (WORLD_BIBLE / no-filler, субъективно)

- [ ] С одного взгляда понятно: здесь живут, здесь «дом» (огонь +
      кружки + палатки = мотив «дом», ENV_STORYTELLING).
- [ ] Каждый объект отвечает на вопрос «какой бит несёт?» — если
      объект не несёт бита (gameplay/visual/narrative/discovery/
      interaction) — он лишний, убрать (правило no-filler).
- [ ] Столб (A2): «YOU HAVE BEEN HERE BEFORE.» — ощущение узнавания,
      а не загадки-головоломки.
- [ ] Записка (A8): «You left a kettle last time. I washed it.» —
      читается за секунду, тёплая, не экспозиция.
- [ ] Чайник у огня (A9/M2.1): место биты про «в прошлый раз»
      подготовлено.
- [ ] Силуэты зон не раскрывают контент зон (только «там что-то
      есть» — геометрия Phase 7).

## KNOWN (осознанные ограничения фазы)
- Интеракты — прототипы: prompt + сигнал, эффект контента —
  Phase 4 (combat/beat), Phase 10 (dialogue Mara), Phase 11
  (echo/note).
- 8 зон — только monolith-silhouette (WORLD_BIBLE: геометрия зон —
  Phase 7).
- Деревья/предметы — примитивы на палитре (art-pass и лицензированные
  ассеты — по мере фаз, ASSET_LICENSES); конусы = 3-ребёрные
  цилиндры (ограничение wasm-рига, ADR-022 — в редакторе можно
  заменить на ConeMesh без изменения кода).
- Звука нет (Phase 12), персонаж — процедурный placeholder (Phase 13).
- Бюджет draw calls (env ≤ 90) будет замерен формально в Phase 16;
  оценка фазы: ~60 (деревья = 3 MultiMesh-calls, лагерь ~30,
  зоны 8x2, landmarks ~6, тропа ~3).
