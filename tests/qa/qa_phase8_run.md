# QA Phase 8 — Run system (scripted first 10 min)

Цель: «забег → смерть → новый забег: полный цикл; «Что
изменилось» читается; A1–A17 срабатывают (playtest по
FIRST_30_MINUTES)» (ROADMAP Phase 8 exit). Риг-покрытие:
**823 проверки** (unit 584 + integration 239; новый сьют
run_cycle — полный цикл в одной сцене: RUN 1 A-якоря → смерть
(A19) → respawn-реконструкция (41 ms wall-time, бюджет ≤ 2 s)
→ RUN 02 (подвал открыт, канон в шахте и подбирается, B2-реплика,
посох в святилище, Ния в деревне) → run-запись (PLAYER_DIED/
ENEMY_KILLED/ATTACK/ENTER_ROOM/NPC_TALKED/EVENT_COMPLETED/
NOTE_WRITTEN, ITEM_PICKED в RUN 2, JSON-раундтрип) +
run_system: recorder limits (4096/сэмплирование/5 МБ),
derive_seed, changed_lines, history).

Важно: (1) RUN 1 = канонический seed сессии (20260917) —
якоря ниже воспроизводимы; с RUN 2 раскладка новая
(ADR-027). (2) В RUN 1 ящики с оружием — **записки** (почерк
E.), само оружие появляется с RUN 02 (A14/A15). (3) Watcher —
invulnerable (данные).

## A. Playtest первых 10 минут (RUN 1)

Запустить игру (release-feature или debug — без F-клавиш).
Ожидать: чёрный fade 2 с, без меню (A1), лагерь.

1. **A2 — столб** (справа у костра): подойти, E.
   → тост с текстом о столбе; флаг `pillar_seen`.
2. **A3 — первый взмах**: атака (кнопка атаки).
   → тост «клинок помнит руки»; далее взмахи без тоста.
3. **A5 — первый Hollow**: убить первого пепельного в
   лагере (30 HP, 2–3 взмаха).
   → растворение; **запомнить место** (в RUN 02 там будет
   след).
4. **A7 — записка у костра** (note stand): E.
   → записка **своим почерком** («If you find this, don't
   trust the version of me that comes before me…»).
5. **A10 — фигура**: пройти через ворота в деревню.
   → впереди ~30 м — копия игрока; поворачивает голову (0.6 с),
   гаснет (1 с), следы (10); без боя.
6. **A11 — Ния в деревне** (не в лагере): E.
   → каноническая реплика (trust-линия).
7. **A12 — костёр деревни**: подойти.
   → пепел одного из пяти шалашей (визуал + флаг).
8. **A16 — Ancient Gate** (через гейт): подойти к вратам.
   → гравировка (sealed), тост, три «ноутбука предшественника»
   у подножия.
9. **A15 — Old Shrine**: подойти к нише.
   → «шёпот» (визуал-пульс + тост); в RUN 1 **никакого
   оружия** — только записка в нише.
10. **A17 — озеро**: note stand у берега, E.
    → записка «охранника озера».
11. **A14 — шахта**: ящик у входа — **записка**, не канон
    (E); чтение → флаг.
12. Вернуться в лагерь.

## B. A19 — первая смерть

1. Умереть (любой враг; Watcher не убивает — invulnerable).
   → death screen: «вы умерли. Мир запомнил.» + 3 Inheritance
   (выбрать 1, ≤ 10 s — время выбора не ограничено таймером).
2. Выбор → respawn:
   - лагерь, hp 100, **без таймера ожидания** (бюджет
     реконструкции ≤ 2 s — в риге 41 ms);
   - overlay «Что изменилось» (3 s, пропускаемый): строки
     «The door past the gate has opened.», «The cannon waits
     in the mine.», «The staff waits at the shrine.», «The
     kettle at camp is clean. (Mara.)» (≤ 5 строк, без
     чисел);
   - тост «Again?» (один раз за сессию);
   - **след первого убийства** (A5) — метка в том месте, где
     пал Hollow.
3. Проверить RUN 02:
   - **B2**: Ancient Gate — дверь открыта (была sealed);
     первая реплика-мысль Eli «That wasn't there.»;
   - **B3**: шахта — ящик теперь **с канном**; (E) → loadout,
     ammo 5; записка у ящика исчезла;
   - **B5**: святилище — ECHO STAFF в нише;
   - Ния — в деревне (не «зависла» в лагере);
   - кетл в лагере: E → «It's clean. Warm, even.» (B1 —
     Мара).
4. Раскладка RUN 02 отлична от RUN 1 (комнаты/порядок
   иные), дверь в подвал (последняя комната шахты) **открыта**
   (в RUN 1 была sealed).

## C. Регрессия (быстрые)

- Camp: костёр/палатки/Мара/стол с кружками — без изменений;
  кетл: RUN 1 E → «The kettle is cold.»
- Бой: урон/riposte/hit-stop — без изменений (combat_scene).
- Death screen: 1/3, перманентный выбор (world state).
- Touch-layout и aspect-проверки — без изменений.

## D. Измерения (обязательно, «no fine without numbers»)

- Время реконструкции на respawn: замерить (debug-лог
  `cycle: the death->respawn rebuild is under 2 s (%d ms)` в
  integration run_cycle — референс рига 41 ms; на железе —
  Phase 16).
- Размер секции runs после 3–5 смертей: ≤ ~150 КБ (MVP,
  ADR-004; 5 МБ-кэп со сжатием старых в summary).
