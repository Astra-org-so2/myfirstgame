# QA Phase 2 — Player (movement, camera, touch)

Цель: movement «приятный», dodge i-frames читаемы, touch-контролы
играбельны на устройстве (ADR-021). Риг-покрытие: 120 проверок —
42 smoke + unit (player_data 16, movement_logic 29, camera_rig 14,
touch_layout 4) + integration (player_scene 15: движение/стоп/dodge с
i-frames/hitstun/respawn через mock-порт на ручном clock, ADR-022).
В редакторе/на устройстве проверяется то, что риг не видит: физика,
рендер, feel, тач.

## A. ПК-редактор (Godot 4.7.2, F5)

- [ ] Запуск без ошибок в Output (вкл. отсутствие ошибок скриптов).
- [ ] Вид от камеры игрока: персонаж (капсула + визор) в центре, hub вокруг.
- [ ] WASD/стрелки — движение относительно камеры (камера — MMB-drag).
- [ ] Shift — спринт (stamina-полоска позже; пока — по скорости),
      exhaustion: спринт кончается, бежит медленнее, после паузы — снова.
- [ ] Space — dodge: короткий рывок по направлению движения (или facing),
      squash-анимация; двойной dodge сразу — НЕ проходит (cooldown).
- [ ] Камера: MMB-drag — орбита; pitch ограничен; у стены камера
      подтягивается (не проходит сквозь), FOV расширяется.
- [ ] Геймпад (если есть): stick L — движение, stick R — камера,
      B — dodge, Y — спринт, X — attack (заглушка, Phase 4), dpad — камера.
- [ ] Стены хаба: движение не проходит сквозь, камера не проваливается.
- [ ] Respawn: (пока — через debugger: `player.respawn(Vector3.ZERO)`)
      — позиция/стamina/состояние сброшены.

## B. Android-устройство (debug-экспорт или Godot-remote)

- [ ] Touch-слой виден (джойстик слева, DODGE/ATK/USE/INV справа),
      не вылезает за safe area (notch).
- [ ] Джойстик: плавное движение во все стороны; отпустил — стоп.
- [ ] Кнопки: DODGE — рывок, ATK/USE/INV — события (Phase 4+, пока —
      отклик визуально + log).
- [ ] Drag-камера (правая зона): плавная орбита, без рывков.
- [ ] Мульти-тач: джойстик + камера одновременно — работают вместе.
- [ ] Aspect 20:9: layout не ломается (нормализованные координаты).
- [ ] 60 fps при беге/додже (F1 overlay, Phase 16 формализует).

## C. Feel-чек (субъективно, фиксация в PERF_REPORT позже)

- [ ] Движение отзывчивое (ускорение/торможение без «ватности»).
- [ ] Dodge «хрустящий»: старт мгновенный, окно i-frames ощущается.
- [ ] Камера не тошнит (сглаживание, pitch-лимиты).
