# AFTER YOU — Game Design Document (GDD)

Версия: 0.1 (Phase 0, pre-production)
Дата: 2026-09-13
Статус: НА РЕВИЗУ (решения, требующие подтверждения игрока-владельца проекта, помечены `?`)

---

## 1. Видение

**AFTER YOU** — 3D third-person action roguelite, в котором мир помнит предыдущие
прохождения игрока.

Одна игровая мысль, от которой не отказываемся ни в одной фиче:

> **После смерти прошлый забег не исчезает. Он остаётся в мире.**

Игрок встречает следы своих прошлых действий: оставленные предметы, открытые
двери, убитых NPC, призраков (ghosts) предыдущих жизней, врагов, собранных из
данных прошлых забегов. Цель — ощущение: **«этот мир действительно помнит меня»**.

Анти-видение (what we are NOT):
- не «ещё одна» прокачка/гейминг;
- не огромный мир; не контент-фабрика;
- не survival-crafting; не кооператив;
- не хоррор-скап (мистика да, jump-scares нет).

## 2. Стилистический тон

- **Меланхоличный, загадочный, опасный.** Забытый лес, руины, туман.
- Свет: прохладный ambient + тёплые очаги (факелы, костры, святилище) — контраст
  «безопасное/опасное».
- Стриминг-аналог для настроения: Hollow Knight (сентиментальность), Dead Cells
  (бой и темп), Limbo/Inside (окружающая повествовательность).
- UI: «часть игры», не Godot-дефолт. Тёмный wood/parchment, тонкие линии, без
  стеклянных панелей.

## 3. Целевое переживание (target experience)

| Момент | Эмоция | Что её создаёт |
|---|---|---|
| 0:00–0:30 | «выглядит красиво» | Хаб-поляна Forgotten Forest: туман, свет факелов, силуэты руин |
| 0:30–2:00 | «управление приятное» | Бег/уворот с i-frames, камера без lag, отзывчивый атака |
| 2:00–5:00 | «о, интересная механика» | Первый Echo/след прошлого: «я оставил этот меч в прошлый раз?» |
| ~60 min | «игра реально запоминает?» | Сводка «Что изменилось» после смерти + видимые перманентные изменения |
| 1-я смерть | «что изменилось?» | Death screen показывает следы забега |
| 2–3-я смерть | «мои прошлые персонажи реально существуют?» | Ghost предыдущей жизни бегает по хабу, повторяет действия |
| далее | «что будет, если я специально сделаю X?» | Скрытые world-события от действий (mysteries) |

**Retention loop:** забег (15–25 мин) → смерть → «что изменилось?» → следующий
забег с целями «я хочу, чтобы в мире осталось вот это» → новые следы → mystery-
ломика → смерть/победа → loop.

Критический параметр loop: **смерть → возрождение в хабе ≤ 10 секунд**
(включая death screen). Всё, что замедляет loop, — bug.

## 4. Геймплей

### 4.1 Игрок

- Third-person, свободное 3D-перемещение, камера от третьего лица (orbit,
  collision, auto-FOV-компенсация).
- Действия:
  - Move / Sprint (stamina)
  - Dodge (i-frames 0.15–0.25s, cooldown 0.4–0.6s, stamina)
  - Basic attack (melee combo 2–3 удара, data-driven weapon)
  - Ranged attack (у части оружия: бросок/выстрел, limited ammo per run)
  - Interaction (E / RB): предметы, NPC, двери, святилища, «мемориальные» объекты
  - Inventory (открытие: Tab / Select; 12 слотов + equipment slots)
  - Upgrade selection после смерти (выбор 1 из 3 «наследий» — между забегами,
    перманентные; см. 4.4)
- Health (HP), Stamina, Damage, Death.
- Урон игрока: hit-stop 40–60ms, camera shake (малый), красная vignette,
  knockback. Не «ватность», не «камера отваливается».

### 4.2 Бой

Приоритет: **readability + feel** при малом количестве контента.
- Hit detection: hitbox/hurtbox (physics layers, см. TECHNICAL_DESIGN),
  damage resolution через единый `DamageResolver`.
- Knockback, hit reaction (статер 0.2–0.4s у врагов), hit-stop, camera shake,
  impact particles, sound. Умеренно: «juice without visual noise».
- Telegraphs у врагов обязательны: 0.4–0.8s (melee windup), видимый маркер на
  земле/на враге. Догдаться telegraph = i-frames dodge.
- Boss (Phase 12): фазы, telegraphs, уязвимое состояние (guard-break после N
  парирований/ударов по ядру), death sequence.

### 4.3 Враги (5 архетипов, каждый — отдельная система поведения)

| Архетип | Роль | Ключевое поведение |
|---|---|---|
| **Stalker** | быстрый melee | патрулирует, при детекте — рывок-сближение, серия из 2 атак, «затаивание» (стоп-статус) |
| **Brute** | медленный тяжёлый | 2-ударная telegraph-атака, slam с AoE-клингом, после слэма — recovery |
| **Watcher** | ranged | держит дистанцию, 3 снаряда в pattern (веер/прямая/арка), телепорт-перезалп |
| **Mimic** | копия игрока | **копирует последнее используемое игроком оружие** из данных текущего/прошлого забега — тематический враг |
| **Echo** | «ваше прошлое» | **собирается из данных предыдущего забега**: повторяет паттерн действий игрока (attack sequence), сложность/оружие = из run-логов |

У каждого: state machine (Idle / Detect / Chase / Attack / Hurt / Recovery /
Death), навигация (NavMesh, A*), выбор цели (range + LOS + aggro), staggered
updates (см. PERFORMANCE). Никаких 5 копий одного врага: у каждого архетипа
свои data-ресурсы + своё поведение-расширение FSM.

### 4.4 Лут и прогрессия (data-driven)

- **Внутри забега (run-scoped):** оружие (3 на MVP: melee sword / dagger+poison?
  `?` — набор уточняется), зелья (лечение, stamina), расходники, «осколки»
  (currency) → апгрейды в конце забега.
- **Между забегами (meta-scoped):** «Наследия» (legacy upgrades, 10–15 шт.):
  пассивные усиления (HP+, dodge cooldown−, урон+, детект-радиус врагов− и т.п.).
  Покупка за осколки + «память» (особая валюта за completion mysteries).
- Инвентарь: 12 слотов, stacking по типу, «мёртвый груз» не остаётся в инвентаре
  между забегами (кроме осколков/наследий) — предметы, оставленные в мире,
  остаются в мире (механика памяти!).

### 4.5 Мир: The Forgotten Forest

Один биом, маленький, плотный, каждый метр с нарративом.

- **Хаб (Clearing):** поляна с лагерем, святилищем, NPC (The Keeper — старый
  хранитель, «знает» игрока). Возрождение здесь. Мемориальные изменения мира
  применяются в хабе в первую очередь.
- **Ареалы (8):** каменное кольцо (ruins), заброшенная хижина (cabin), мост
  через болото (bridge), второй лагерь (camp), грот (cave), подполье
  (underground), священная роща (shrine grove — **включает босс-арену
  heartgrove** на глубине), поляна эха (echo field). Итого локаций: 9
  (хаб + 8) — см. ADR-010.
- **Landmarks** (видны из хаба или на подходе): разрушенная часовня, поваленное
  гигантское дерево с факелами, «мёртвое» озеро, каменный круг.
- **Процедурность:** hand-authored комнаты + процедурный выбор вариантов и
  связей (см. ADR-003): порядок/набор комнат в ареале, спавны врагов, лут,
  события — по seed. Геометрия-«якоря» (двери, ключевые точки) стабильны между
  забегами — это фундамент системы Ghost.
- Размер: полный забег до boss-арены ≈ 15–25 минут активного геймплея.
  Обход всех секретов — 40–60 минут.

### 4.6 Система мира-памяти (World Memory)

Перманентные состояния (WorldState, живут между забегами):
- `opened_shortcuts`, `unlocked_rooms`
- `killed_npcs` (включая опциональных — с последствиями)
- `completed_events`, `discovered_locations`
- `dropped_items` (предметы, оставленные/выпавшие в мире, с локацией)
- `important_choices` (двоичные выборы, влияющие на mysteries и финал)
- `previous_runs` (компактная история: seed, duration, death cause, kills,
  major actions; полные логи — для последних 3 забегов, см. ADR-004)

Правило видимости: **любая перманентная перемена должна быть видимой за 1
секунду** (визуальный шиммер на «мемориальных» объектах, сводка «Что
изменилось» на death screen и в начале забега). Если игрок не заметил —
дизайн не сработал, исправляем.

### 4.7 Ghost-система (для игрока)

- После первой смерти предыдущая жизнь становится ghost: полупрозрачная,
  холодная палитра, лёгкий «посвет», движется по записанным данным.
- Ghost виден в хабе (и в локациях, которые он посещал), повторяет ключевые
  действия: бег, атаки (видимая, но «пустая» анимация урона), взаимодействия
  (открывает тот же сундук, к которому шёл).
- Ghost **не взаимодействует физически** с игроком (не тратит ресурсы, не
  читается как цель) — исключение: scripted moments (mystery #4: «досмотри
  ghost до конца его действия»).
- При новых смертях ghost заменяется последним забегом; старые превращаются в
  «следы» (отпечатки/маркеры на земле — дешёвая VFX).

### 4.8 Mystery-система (5 основных, MVP)

Мета-вопрос, на который ответы собираются постепенно: **«кто я и почему этот
лес помнит именно меня?»**

1. **M1 — Святилище имён.** Камень со списками имён/дат/причин смерти. После
   первой смерти появляется строка «вашего» имени. Ответ: вы умирали здесь
   раньше — много раз.
2. **M2 — Дневник хижины.** Дневник, написанный почерком игрока (объект в мире
   + close-up UI). Записи описывают события, которые произойдут в следующих
   забегах (данные из run-логов прошлого). Ответ: «автор» — это вы из прошлой
   жизни; вы знали, что умрёте.
3. **M3 — Хранитель (NPC).** The Keeper говорит «не вы первый, кто приходит к
   этому огню». Отношение меняется по world-state (вы убили/помогли/оставили
   у него предмет). Ответ: он помнит все ваши смерти — и молчит о причине.
4. **M4 — Ghost на лагере.** Ghost последней жизни на лагере повторяет
   действие, которое вы никогда не завершали (открыть сундук/заговорить с
   NPC). Присутствие рядом (не убивать ghost-момент — scripted safety) →
   ghost «завершает» действие и оставляет записку. Ответ: прошлая вы хотела,
   чтобы кто-то (будущая вы) это увидел.
5. **M5 — Сердце Рощи (boss-момент).** В death sequence boss и в финальных
   репликах Keeper: лес — «память» сущности, которая коллекционирует жизни;
   boss = сумма всех ваших смертей. Выбор финала (`important_choice`): отдать
   память (boss умирает, мир «забывает» вас — перманентный soft-lock части
   мира) или забрать её (победа, но мир остаётся с вашими следами —
   «посвящённый» режим сложности).

Не раскрывать всё сразу: каждая mystery даётся по 2–3 фрагмента на 2–3
забега. Механика «проверки»: после каждой mystery-встречи игрок должен
«досмотреть»/«прочитать» — без quest-UI (только world-объекты + журнал
записок в inventory, «Памяти»).

## 5. MVP-объём (жёстко)

- 1 персонаж (rigged, CC0)
- 1 биом (Forgotten Forest), 9 локаций (хаб + 8; босс-арена — внутри рощи)
- 1 маленький procedural world (варианты комнат, seed, connections)
- 5 врагов (Stalker, Brute, Watcher, Mimic, Echo)
- 3 оружия
- 10–15 legacy upgrades
- 1 boss (heartgrove)
- 1 NPC-хаб (The Keeper)
- 5 mystery-событий
- World memory + run recording + ghost + save/load
- UI (health/stamina/prompt/inventory/dialogue/pause/settings/death/run summary/
  upgrade selection), keyboard+mouse+gamepad, touch-ready architecture
- Audio (footsteps, hits, UI, ambient, 2–3 музыкальных трека) + VFX
- Quality settings (Low/Med/High/Ultra)
- PC-playable build (Windows x86_64 + Linux x86_64 `?` приоритет платформ)

**Не в MVP (explicitly out):** мультиплатформенный релиз Android (только
архитектурная готовность), 2+ биомов, кооп, перк-травл (build-variety) глубже
legacy, локализации (RU/EN — EN primary `?`).

## 6. Метрики успеха (для QA и ревизий)

- Death→respawn ≤ 10 c (замер, Phase 16)
- 60 fps на GTX-1060-классе @High, 1080p (Phase 16)
- «Что изменилось» замечено без подсказки: ≥70% тестовых сессий (ручное QA,
  Phase 17, N≥10)
- Zero unknown-лицензии ассетов (Phase 19, проверка по ASSET_LICENSES.md)
- Crash-free rate: 0 known critical, 0 save corruption на тест-матрице (Phase 15/17)
